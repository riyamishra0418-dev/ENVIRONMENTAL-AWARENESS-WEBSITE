# 🌿 EcoSphere | Save Our Planet

EcoSphere is a web project dedicated to environmental awareness, sustainability, and promoting greener habits[cite: 1].

---

## 📁 Files Included

* **`index.html`**: Contains the main structure, layout, and content sections including the hero banner, sustainability guide, waste management tips, news gazette, interactive facts, quiz, and pledge form[cite: 1].
* **`style.css`**: Handles the styling, CSS variables, layout grids, animations, and dark mode support[cite: 3].
* **`script.js`**: Powers the dynamic features, including mobile menu navigation, theme switching, news slideshow, fact popups, quiz logic, and pledge handling[cite: 2].

---

## ✨ Features

* **Responsive Navbar**: Clean layout with a mobile menu toggle and a light/dark theme switch[cite: 1, 2, 3].
* **Interactive Planet Post**: A newspaper-style slideshow featuring global environmental stories[cite: 1, 2].
* **Little Green Wonders**: Clickable cards revealing bite-sized ecological facts[cite: 1, 2].
* **Eco Quiz**: A multi-question interactive quiz to test your environmental knowledge[cite: 1, 2].
* **Green Pledge**: A form allowing visitors to commit to a personal eco-friendly habit[cite: 1, 2].

---

## 🚀 How to Run

1. Clone or download the repository files (`index.html`, `style.css`, and `script.js`) into a single folder.
2. Open `index.html` in any web browser.
